# Foreword

**Ur/Web** is a statically typed functional language for web applications with strong guarantees about HTML, RPCs, SQL, and marshaling. The **original** implementation is described at [impredicative.com/ur](http://www.impredicative.com/ur/) and maintained at [github.com/urweb/urweb](https://github.com/urweb/urweb).

This guide focuses on the same **language ideas** while documenting how to work with the **Rust** toolchain in this repository: building projects, using the LSP, and understanding how the compiler mirrors the classic pipeline.
