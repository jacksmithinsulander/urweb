# Getting started

1. Install **Rust** and clone this repository.
2. Build the toolchain: `cargo build --release` from the repo root.
3. Create a project: `ur new myapp` then `cd myapp` and `ur build`.

Consult the main [README](../../README.md) for CLI overview, CI parity commands, and links to the reference manual (PDF) for the full Ur/Web language definition.
