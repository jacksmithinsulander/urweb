# Introduction

This book is a **structured guide** to **Ur/Web** and this repository’s **Rust-based** compiler, in the spirit of [*The Rust Programming Language*](https://doc.rust-lang.org/book/). Chapters will grow here over time: language concepts, the compilation model, project layout (`ur.toml`, `.urp`), safety properties (including links to LangSec-oriented tooling behavior), and pointers into [ARCHITECTURE.md](../../ARCHITECTURE.md) for implementation detail.

For a more informal, example-first path, see [Learn Ur/Web](../tutorial/) in this repo.
