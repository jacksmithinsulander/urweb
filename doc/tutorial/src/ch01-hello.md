# Hello, Ur/Web!

Welcome! This tutorial will eventually walk through Ur/Web the way *Learn You a Haskell* walks through Haskell: **light tone**, **lots of examples**, and intuition before formalism.

For now, start with a tiny program. After `ur new greeter` and `ur build`, explore the generated files. The **authoritative** language reference is still the [Ur/Web manual (PDF)](http://www.impredicative.com/ur/manual.pdf).

When you want a chapter-style reference, open [The Ur/Web Guide](../guide/).
